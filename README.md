# 陈金木个人作品集

> 复古军事档案风格的动态网页作品集，含尾兽系列动态海报

## 项目简介

- 风格：复古军事档案美学（羊皮纸底、扫描线、噪点、Oswald 字体）
- 主页：个人作品集，含封面动画、关于、作品、技能、经历、联系等板块
- 子页：火影忍者九只尾兽动态海报档案（bijuu 目录）

## 技术栈

- 原生 HTML / CSS / JavaScript（无构建依赖）
- Tailwind CSS Browser（CDN）
- Lucide Icons（CDN）
- 内联 SVG 图形
